### Descripción
Aplicación de gamificación de limpieza utilizando visión por computadora para rastrear el movimiento físico de una escoba o trapo. Tecnologías usadas: JavaScript, Node.js, Express, Socket.IO, HTML5

### Instrucciones de uso
1. Descargar las dependencias necesarias con `npm install`
2. Conectar mediante depuración USB o inalámbrica un dispositivo móvil al puerto 5500
3. Arrancar el servidor con `npm start`
4. Ir a `http://localhost:5500` en Google Chrome en ambos dispositivos, seleccionar "Ver Suelo" en la pantalla y seleccionar "Usar Escoba" en el móvil
